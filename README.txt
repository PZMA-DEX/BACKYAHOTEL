야간근무: 백야 호텔 — 홈 화면 앱(PWA) 올리는 방법

1. 이 폴더 안의 파일을 전부 GitHub 저장소 맨 위(루트)에 올립니다.
   index.html / manifest.webmanifest / sw.js / icons 폴더(아이콘 5개)
2. 저장소 Settings → Pages 에서 Branch: main, 폴더: / (root) 로 저장합니다.
3. 1~3분 뒤 https://사용자명.github.io/저장소명/ 으로 접속합니다.

설치
- 안드로이드(크롬·삼성 인터넷): 타이틀의 「앱으로 설치하기」 버튼 → 설치
- 아이폰(사파리): 「앱으로 설치하기」 버튼 → 안내대로 공유 → 홈 화면에 추가
- PC(크롬·엣지): 「앱으로 설치하기」 버튼 또는 주소창 오른쪽 설치 아이콘

※ 파일을 고쳐 다시 올렸는데 예전 버전이 보이면, 앱을 완전히 닫았다가 다시 열면 됩니다.
